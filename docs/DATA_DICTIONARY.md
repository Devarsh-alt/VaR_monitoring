# Data dictionary

forecast_date: origin of an issued forecast; realized_date: next observed return date. ticker: fixed-cohort identifier,not proof of historical index membership. model/model_name: HS,EWMA,GARCH-t,QRF. Signed VaR is a lower-tail return quantile; abs(VaR) is the original normalization denominator. actual_return: subsequent observed return aligned to its forecast. deterioration_Hd: original T1 future average normalized loss event. coverage_failure_Hd: separate T2 binomial breach-count label. causal_Hd_loss_threshold: expanding 75th-percentile matured historical-window benchmark. label_start/end_date_Hd: realized-session support of the future outcome. y: target-specific binary event. p_raw: uncalibrated monitor score. p_cal: held-out Platt probability,legacy float32 storage; p_cal_unrounded retained separately in P8. fold: chronological test quarter. spec: exact runtime group mapping in frozen protocol; never infer solely from a label. n_dates: observed trading dates,not calendar-day durations. Stock/date/outcome keys must match before pairing. Whole-date blocks preserve the cross-section. Percentile confidence intervals are marginal; Holm p-values adjust separately within declared families. Source/membership/adjustment-vintage limits remain as documented in P8.
